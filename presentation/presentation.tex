\section{Summary}
\begin{frame}{What the Saved Results Support}
\begin{itemize}
\item \textbf{Local vLLM:} lowest mean latency (6.062\,s), but a 150-token budget and three visibly incomplete answers.
\item \textbf{Ollama:} highest completion rate (34.37\,tok/s), longest total time (83.142\,s), and two explicitly truncated answers.
\item \textbf{Spark:} fastest capital response (0.607\,s); all responses finish with \texttt{stop}. Mean latency is 10.464\,s and sample standard deviation is 9.408\,s.
\end{itemize}
\begin{alertblock}{Interpretation}
These snapshots show tradeoffs in output length, reasoning and completion. They do not establish the best backend, equal answer quality, or predictable latency under load.
\end{alertblock}
\end{frame}
\begin{frame}{A Fairer Follow-Up Benchmark}
\begin{enumerate}
\item Match prompts, token budgets and reasoning settings; compare the same model where possible.
\item Record server versions, hardware, quantization and warm-up conditions.
\item Repeat each prompt; retain full answers, finish reasons and usage details.
\item Separate completion throughput, time to first token and concurrent serving capacity.
\item Evaluate correctness and completeness alongside descriptive text metrics.
\end{enumerate}
\end{frame}
